កូដស្ថានភាព · Status Codes

⚠️ ហៅពី server របស់អ្នកតែប៉ុណ្ណោះ — កុំហៅពី browser ឬកូដ client-side; API key របស់អ្នកគឺជាសម្ងាត់។ Call from your server only — never from a browser or client-side code; your API key is secret.

2xx · Success · ជោគជ័យ

200OK — សំណើជោគជ័យ · Request succeeded
201Created — បានបង្កើតហើយ (ឧ. ចម្រៀង/រូបភាពថ្មី) · Resource created

3xx · Redirection · ប្តូរទិស

API នេះមិនត្រឡប់កូដ 3xx ក្នុងការប្រើប្រាស់ធម្មតាទេ។ This API does not return 3xx codes in normal use.

4xx · Client Error · កំហុសពីអ្នកហៅ

400Bad Request — ទិន្នន័យមិនត្រឹមត្រូវ · Invalid request data
401Unauthorized — Key មិនត្រឹមត្រូវ (api_key_invalid) / ផុតកំណត់ (api_key_expired) · Invalid or expired key
402Payment Required — អស់ Credits · Out of credits
403Forbidden — Key ត្រូវបានលុប/បិទ — សិទ្ធិត្រូវបានបិទ (api_key_revoked) · Key revoked/blocked — permission is closed. ហៅពី browser / image_requires_package ក៏ 403 ដែរ · Browser Origin rejected, or image needs a paid package
404Not Found — រកមិនឃើញ · Resource not found
429Too Many Requests — ហៅច្រើនពេក សូមរង់ចាំ · Rate limited, try again later

403 = Key ត្រូវបានលុប/បិទភ្លាមៗ — អ្នកហៅដឹងភ្លាមថាសិទ្ធិត្រូវបានបិទហើយ។ A blocked key answers 403 at once, so the caller knows immediately the permission was revoked.

5xx · Server Error · កំហុសពី server

500Internal Server Error — កំហុសខាង server · Server error
503Service Unavailable — API ត្រូវបានបិទដោយម្ចាស់ / video_not_available_yet (Generate Video មិនទាន់បើក) · API disabled by the owner, or video generation not open yet
